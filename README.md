This repository held the old **Python script** version of the editor (the early v8–v9 versions with a desktop window).

**Please use the online editor instead.** It is free and needs no download or install. It works on phone and desktop, comes in 6 languages and is always up to date with the newest game patch. It also has every feature this version had, plus much more.

## Why the move?
Running a Python script meant installing Python and dealing with versions and dependencies. The online editor needs none of that: you open a link and edit. It is also miles ahead of the old script.
